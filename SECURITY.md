# Security Policy

Mouse Without Borders handles input, clipboard contents, files, and network connections between trusted computers. Please do not post an unpatched vulnerability, security key, private prefs file, IP address, private log, or proof-of-concept exploit in a public issue.

Use GitHub's private **Report a vulnerability** option on the repository's **Security** tab when available. Otherwise, contact the repository owner privately through GitHub before sharing technical details.

Include the affected release/tag, Windows version, portable or installed mode, reproduction steps, likely impact, and a minimal safe proof of concept when possible. Only the newest release is supported.

This is an unofficial community fork with no response-time guarantee or bug-bounty program. It intentionally supports normal interactive desktops only and does not install a service for protected UAC/sign-in desktops. Protect `MouseWithoutBorders.prefs.json`, because it contains the shared security key.
